# Структура данных прогресса уроков

Этот документ описывает, как бот вычисляет состояние обучения и какие инструменты доступны для ручной корректировки.

## Таблицы и поля

### `funnel_progress`
- `lesson_num` — номер урока (1–4).
- `hw_status` — состояние домашнего задания (`submitted`, `pending`, `skipped`).
- `delivered_at`, `opened_at` — даты выдачи и открытия урока.
- `hw_answer` — текст ответа на задание.

### `lesson_feedback`
- `lesson_num` — номер урока.
- `feedback_type` — код отзыва (например, `excellent`, `good`).
- `feedback_text` — необязательный текстовый комментарий.

Если в `funnel_progress` нет записи, но есть отзывы в `lesson_feedback`, урок считается завершённым. Это позволяет корректно отображать импортированные данные.

## Логика отображения

- В блоках «Мой прогресс» и «Профиль» статусы строятся по комбинации `hw_status` и наличия отзывов.
- Отображается статус доступа («Без подписки», «Активный доступ», «Доступ истёк») и дата окончания в формате `ДД.ММ.ГГГГ`.
- Для каждого урока показываются иконки: `✅` — завершён, `⏳` — в работе, `⏭️` — пропущен, `🚀` — готов к старту, `🔒` — закрыт. При наличии отзывов добавляется пометка с количеством отзывов.

## Ручная корректировка

### Через админ-панель бота

В карточке пользователя (админское меню «👥 Пользователи») доступна кнопка «📈 Обновить прогресс». Отправьте одну или несколько строк вида:

```
lesson=1 status=submitted feedback=excellent,good delivered=2024-08-01 opened=2024-08-05
lesson=2 reset=1
```

Поддерживаемые параметры:
- `lesson` — номер урока (обязателен).
- `status` — новое значение `hw_status` (`submitted`, `pending`, `skipped`).
- `feedback` — список кодов отзывов через запятую. Пустое значение (`feedback=`) удаляет отзывы.
- `delivered` / `opened` — дата в ISO-формате.
- `answer` — текст ответа на ДЗ.
- `reset=1` — удалить прогресс и отзывы по уроку.

### REST API

| Метод | URL | Описание |
| --- | --- | --- |
| `GET` | `/admin/progress?secret=...&user_id=123` | Возвращает статусы уроков, количество отзывов и дату доступа. |
| `POST` | `/admin/progress/sync?secret=...` | Принимает JSON вида `{ "user_id": 123, "lessons": [{"lesson": 1, "status": "submitted", "feedback": ["excellent"]}] }` и синхронизирует данные. |

Параметр `actor_id` позволяет зафиксировать действие в `admin_log`. Поле `feedback` с пустым массивом очищает отзывы, `reset: true` удаляет урок целиком.
