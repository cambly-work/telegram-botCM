# Регрессионный чек-лист релизов

## Общие проверки
- [ ] Установлена и загружена актуальная конфигурация (`settings.py`, переменные окружения).
- [ ] Бот успешно запускается локально (`python app.py`) и/или в Docker.
- [ ] Команда `/start` показывает главное меню для зарегистрированного и нового пользователя.
- [ ] Проверена работоспособность уведомлений администраторам (ручной прогон ключевых сценариев из smoke-тестов).

## Регистрация и профиль
- [ ] Регистрация нового пользователя: имя → email → телефон, сообщения валидации отображаются корректно.
- [ ] Обновление email/телефона в профиле с проверками формата.
- [ ] Возврат в меню после завершения регистрации.

## Бесплатные уроки и домашние задания
- [ ] Получение урока, отметка выполнения, отправка вопроса и отмена вопроса.
- [ ] Сохранение отзывов (кнопки и свободный текст), показ клавиатуры «После урока».
- [ ] Проверка отправки уведомлений администраторам по вопросам уроков.

## Тестирование и заявки
- [ ] Сбор даты рождения и имени, отправка заявки и уведомление админов.
- [ ] Отмена заявки в любой точке отправляет уведомление об отмене.
- [ ] Повторные заявки корректно перезаписывают данные пользователя.

## Админ-панель и рассылки
- [ ] Просмотр и обновление текстов, материалов, расписания.
- [ ] Создание, редактирование и отправка рассылки (включая смену сегмента, сохранение шаблона).
- [ ] Обработка ошибок при отправке рассылок и их логирование.

## Интеграции и платежи
- [ ] Обработка вебхуков YooMoney/AT: создание/обновление платежей, назначение доступа.
- [ ] Обработка ошибок интеграций (отсутствие пользователя, невалидные контакты) не приводит к падению бота.
- [ ] Сохранение и разбор логов (`app.log`) после тестового прогона.

## Локализация и контент
- [ ] Проверка ключевых текстов (`content.yaml`, административные шаблоны) на актуальность.
- [ ] Соответствие подсказок по email/телефону локализованным сообщениям.
- [ ] Просмотр и обновление контента через админку отображает корректные пояснения.

## Автоматизация
- [ ] `pytest` проходит без ошибок (включая smoke-тесты FSM).
- [ ] План обновления тестовых фикстур/данных при изменении схемы БД.
- [ ] Обновлены документы по ручному тестированию, если изменился функционал.
